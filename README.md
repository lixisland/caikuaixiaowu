# 彩块小屋

一个装在单个网页里的小游戏合集，点开就能玩，不用下载，也不用登录。

🎮 **在线玩**：https://lixisland.github.io/caikuaixiaowu/

## 里面有什么

- **彩块归位** —— 点列顶的小圆点，把溢出的色块送进队列；整列变成同一个颜色，就完成一列
- **记忆翻牌** —— 翻开卡片找配对，8 对全部配上就过关
- **彩块堆消** —— 点没有被压住的色块放进下面的槽里，三个同色自动消除；堆和槽都清空就赢了

## 装扮

六套皮肤随心换，三个游戏通用，翻牌的卡面也会跟着换：

- 哑光莫兰迪
- 奶油马卡龙
- 果冻光泽
- 玻璃方块
- 奶蛋
- 奶蛙家族

## 小提示

- 归位没有步数限制，也不会失败，慢慢理就好
- 堆消只能点最上面没被压住的块；槽里攒满 7 个还没凑齐三个同色，就要重来啦
